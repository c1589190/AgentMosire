# Spec Delta

## Purpose

为 Java 嵌入和独立服务提供同一套会话上下文行为。宿主可以替换压缩策略，运行时负责维护消息顺序和历史，并在下一次模型请求中投递父级异步回复。

## ADDED Requirements

### Requirement: 上下文元素与会话所有权

AgentLib SHALL 提供单条消息及其文本、工具调用、工具结果和图片引用等值对象。Brain SHALL 负责会话窗口、模型请求组装和历史写回，并向嵌入宿主提供会话运行时入口。

#### Scenario: 两次输入使用同一会话

- **WHEN** 宿主在同一 Brain 会话中连续发起两轮对话
- **THEN** 第二轮请求按序携带仍对模型可见的第一轮消息

### Requirement: 可替换的上下文压缩

Brain SHALL 提供默认压缩策略和宿主可替换的策略入口，并管理压缩后的模型工作集和会话写回。

#### Scenario: 宿主提供替代策略

- **WHEN** 宿主装配替代压缩策略并满足压缩触发条件
- **THEN** 运行时采用该策略的结果生成后续模型请求

#### Scenario: 压缩后的模型请求仍携带本轮新图

- **WHEN** 带图片的历史被压缩且本轮还有等待发送的新图片
- **THEN** 摘要请求使用文字历史，本轮新图片随主模型请求发送，原图片引用仍可从本地历史读取

### Requirement: 父级回复的模型投递

Brain SHALL 将父级异步回复投递到对应的子 Agent 会话，在上下文压缩之后、下一次模型请求发送之前加入该回复。成功投递后更新交付状态，会话历史写回仅包含该轮应持久化的消息。

#### Scenario: 模型请求失败后重试投递

- **GIVEN** 子 Agent 有一条已到达且待投递的父级回复
- **WHEN** 携带该回复的模型请求失败，随后重新发起请求
- **THEN** 回复仍待投递，成功后只消费一次，后续请求的历史中没有该次注入的副本
